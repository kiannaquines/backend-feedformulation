Quick Start Guide

Get started with the Feed Formulation System in just a few steps

1

Start the Backend Server

Open a terminal and run the following commands:

cd backend-feedformulation
python -m uvicorn main:app --reload

The backend should start at http://localhost:8000

2

Open the Web Application

You can either:

  • Simply open frontend/index.html in your web browser
  • Or start a local web server (recommended):
    cd frontend
    python -m http.server 8080

    Then navigate to http://localhost:8080

3

Create Your Account

Register a new user account:

  • Click "Register here" on the login page
  • Enter a username, email, and secure password
  • Accept the terms and conditions
  • Click "Create Account"
4

Login to the System

Access your account:

  • Enter your username and password
  • If OTP is enabled, you'll see a verification code
  • Enter the OTP code to complete login
  • You'll be redirected to the dashboard
5

Add Ingredients

Build your ingredient library:

  • Navigate to "Manage Ingredients" from the dashboard
  • Click "+ Add New Ingredient"
  • Fill in ingredient details (name, price, nutritional values)
  • Set minimum and maximum percentages for use in formulations
  • Click "Add Ingredient"
6

Create Your First Formulation

Optimize your feed mix:

  • Navigate to "Create Formulation"
  • Enter nutrient requirements (protein, energy, calcium, phosphorus)
  • Select ingredients to include in the mix
  • Choose an optimization method (HiGHS recommended)
  • Click "Calculate Optimal Formulation"
  • Review the results showing optimal ingredient percentages and cost
  • Save the formulation for future reference

Tips for Best Results

  • Start with common ingredients: Corn, soybean meal, wheat bran, etc.
  • Use realistic constraints: Set min/max percentages based on practical experience
  • Save successful formulations: Build a library of proven recipes
  • Compare alternatives: Try different optimization methods for best results
  • Keep data updated: Regularly update ingredient prices and availability

Troubleshooting Common Issues

Backend not connecting?

Ensure the backend server is running on port 8000 and check for any error messages in the terminal.

No optimal solution found?

This usually means the nutrient requirements are impossible to meet with the selected ingredients. Try adjusting requirements or adding more ingredient options.

Can't login after registration?

Make sure you're using the exact username and password you registered with. Passwords are case-sensitive.
